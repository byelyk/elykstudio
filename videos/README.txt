Drop your video clips into this folder.

PORTRAIT / SOCIAL CLIPS (vertical or square):
  Name them and reference in HTML like:  videos/clip-1.mp4
  Recommended: .mp4 (H.264), muted, under ~10MB each for fast loading.

The <video> tags on the Home page (index.html) and the folder
slides on the Work page (work.html) already point to videos/clip-X.mp4
placeholders — just add files with matching names or edit the src.

YOUTUBE VIDEOS (landscape):
  No file needed. Copy the video ID from the YouTube URL
  (e.g. youtu.be/dQw4w9WgXcQ  →  ID is  dQw4w9WgXcQ)
  and paste it into the iframe src in index.html / work.html.
